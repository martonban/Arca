# Arca
Arca
Arca is a C++ application architecture library. This application is currently in a very early stage of development, primarily due to the fact that it is treated as an entirely hobby project. A broad overview of the current functionality can be found in the examples directory. A roadmap is available in the Arca 0.0.2 release notes.

# Installation:
```Cmake
FetchContent_Declare(
	Arca
	URL https://github.com/martonban/Arca/archive/refs/tags/v0.0.2-alpha.tar.gz
)
FetchContent_MakeAvailable(Arca)
```
